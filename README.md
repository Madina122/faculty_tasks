# 📊 Анализ зарплат по отраслям с учетом инфляции

## 📂 Описание проекта

Интерактивный анализ динамики заработных плат в ключевых отраслях промышленности России (2000-2024 гг.) с поправкой на инфляцию.

## 🔍 Основные возможности

- 📈 Сравнение номинальных и реальных зарплат
- �️ Визуализация по отраслям (рыболовство, химическая промышленность, нефтепереработка)
- 💹 Корректировка данных с учетом инфляции
- 📅 Анализ динамики за 24 года

## Описание датасета

### Данные по зарплатам
- **Источник**: [Росстат](https://rosstat.gov.ru/labor_market_employment_salaries)
- **Период**: 2000-2024 гг.
- **Отрасли**: 
  - Рыболовство
  - Химическая промышленность
  - Нефтепереработка
- **Формат**: CSV с разделителем ";"
- **Кодировка**: UTF-8

### Данные по инфляции
- **Источник**: [ЦБ РФ](https://xn----ctbjnaatncev9av3a8f8b.xn--p1ai/%D1%82%D0%B0%D0%B1%D0%BB%D0%B8%D1%86%D1%8B-%D0%B8%D0%BD%D1%84%D0%BB%D1%8F%D1%86%D0%B8%D0%B8)
- **Показатель**: Годовая инфляция (%)
- **Период**: 2000-2024 гг.
