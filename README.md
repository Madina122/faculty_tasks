# 🐶 Ветеринарный сервис на FastAPI

Простое REST API для работы с базой данных собак. Реализовано с использованием FastAPI.

## 🔗 Демо

Сервис доступен по адресу: [https://pet-clinic-api.onrender.com/docs](https://pet-clinic-api.onrender.com/docs)  

## 📦 Возможности

- `GET /` — корневой маршрут (проверка работоспособности)
- `POST /post` — добавление объекта с временной меткой
- `GET /dog` — получение всех собак или фильтрация по типу
- `GET /dog/{pk}` — получение собаки по `id` (pk)
- `POST /dog` — добавление новой собаки
- `PATCH /dog/{pk}` — обновление данных о собаке по `id`
